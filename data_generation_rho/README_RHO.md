# PFDelta Rho Data Generation

This directory is a copy of `data_generation/` reserved for experiments with
continuous branch-admittance scaling.

The intended first dataset is:

- case: `case30`
- task: `rho_task_1_1_single_edge`
- fixed loop branch
- train load settings: 100
- validation load settings: 20
- test load settings: 20
- train rho grid: `0.0, 0.1, ..., 1.0`
- validation/test rho: `0.0`

The original `data_generation/` directory should remain unchanged.

## Meaning of rho

For one selected loop branch, rho scales the branch series admittance:

```text
y_rho = rho * y_base
```

PowerModels stores the branch mostly as impedance and shunt parameters. The
implemented conversion is:

- `rho > 0`: `br_status = 1`, `br_r = br_r_base / rho`, `br_x = br_x_base / rho`,
  and `g_fr/b_fr/g_to/b_to` are multiplied by `rho`.
- `rho = 0`: `br_status = 0`, which removes the selected branch.

Each `(load setting, rho)` sample is solved again with AC OPF through
PowerModels + JuMP + Ipopt, so generator dispatch is recomputed.

## Entry Point

The rho dataset is generated by:

```bash
cd data_generation_rho
julia --project=. create_rho_dataset.jl --clean
```

This writes:

```text
case30/rho_task_1_1_single_edge/
  meta.json
  raw/sample_*.json
  splits/train.json
  splits/val.json
  splits/test.json
```

Default sample counts:

- train: `100 load settings * 11 rho values = 1100 samples`
- val: `20 load settings * rho=0 = 20 samples`
- test: `20 load settings * rho=0 = 20 samples`

For a quick server smoke test:

```bash
cd data_generation_rho
julia --project=. create_rho_dataset.jl \
  --output-dir tmp_rho_smoke \
  --train-loads 1 \
  --val-loads 1 \
  --test-loads 1 \
  --train-rhos 0,1 \
  --clean
```

Useful options:

- `--branch-id auto`: choose the first loop branch; replace `auto` with a branch
  id to fix a specific branch.
- `--load-sampler polytope`: use the OPFLearn/PFDelta load polytope sampler.
- `--load-sampler uniform`: sample around the base load with `--load-dist-perc`.
- `--perturb-costs none`: keep generator cost fixed to isolate rho effects.
- `--perturb-costs shuffle`: optionally reuse PFDelta-style cost shuffling.

MATLAB is not needed for this AC OPF-rho path.
